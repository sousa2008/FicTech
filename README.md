# FicTech 🚀

Startup acadêmica dedicada ao desenvolvimento de soluções tecnológicas inovadoras, construída como parte do projeto de extensão do curso de Análise e Desenvolvimento de Sistemas (ADS) no IFSP - Campus Guarulhos.

## 📌 Sobre o Projeto
Este repositório armazena o código-fonte da página de apresentação e futuras aplicações da FicTech. A infraestrutura utiliza Integração Contínua (CI) via GitHub, conectada ao ambiente de hospedagem cPanel da disciplina. Qualquer alteração aprovada na `branch main` reflete automaticamente no ambiente de produção.

## 🛠️ Tecnologias e Infraestrutura
* **HTML5 / CSS3:** Estruturação e estilização visual.
* **Git & GitHub:** Versionamento de código e repositório remoto.
* **Integração Contínua (CI):** Deploy automatizado via GIT Version Control.
